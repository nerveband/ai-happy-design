# Cloud Relay Design

Date: 2026-07-08

AI Happy Design remains local-first. A cloud relay should exist only to bridge agents and Figma when they cannot share localhost.

## Pairing Model

- Six-character pairing code, generated by the Figma plugin.
- Code TTL: 10 minutes.
- Single use: first successful agent connection consumes the code.
- Relay room expires when both peers disconnect or after 60 minutes idle.
- No persistent file data by default.

## Transport

- WebSocket relay with two peer roles: `plugin` and `agent`.
- Messages keep the current response envelope unchanged.
- Relay can forward binary-safe JSON payloads, but artifact files should stay local unless explicitly delivered.

## Privacy

- Local relay remains the default.
- Cloud relay is opt-in per session.
- Pairing code grants temporary transport access, not Figma account access.
- Server stores only operational logs: timestamps, room lifecycle, byte counts, and error classes.
- No canvas payload persistence unless the user explicitly opts into diagnostics.

## Failure Behavior

- Expired code returns a clear `PAIRING_EXPIRED` error.
- Already-used code returns `PAIRING_CONSUMED`.
- Idle room returns `ROOM_CLOSED`.
