How it works

This plugin connects to a local relay server that bridges Figma with the CLI and AI tools. Nothing leaves your machine.

Quick start
  1. Install the binary and this plugin
  2. Start the relay: ai-happy-design relay start
  3. Open the plugin — it auto-connects
  4. Use the CLI or ask your AI to start designing
CLI vs MCP

ai-happy-design relay start starts only the relay. Use this for CLI-driven workflows.

ai-happy-design mcp starts both the MCP server (for AI editors like Claude Code, Cursor) and the relay. Use this when connecting through an AI tool.

MCP config 
{
  "mcpServers": {
    "ai-happy-design": {
      "command": "/path/to/ai-happy-design",
      "args": ["mcp"]
    }
  }
}
Channel key

The channel key pairs this plugin with your CLI or AI tool. Both sides must use the same key to communicate.

  • Copy — paste the key into --channel flag or AHD_CHANNEL env var
  • New — generate a fresh key (disconnects current session)
Troubleshooting
  • Relay not running? ai-happy-design relay start
  • Check status: ai-happy-design relay status
  • View logs: ai-happy-design relay logs
  • Wrong port? Edit the relay URL above
