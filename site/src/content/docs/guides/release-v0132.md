`v0.13.2` is the current release.

## Highlights

- 184 schema-backed CLI commands.
- 185 MCP tools including `ahd_describe`.
- Token export from presets or Figma variable snapshots.
- Config-driven CSS, Tailwind, Swift, Android, and JSON token outputs.
- WCAG-oriented accessibility audits.
- Design-code parity comparison.
- Local REST/Figma API helpers for metadata, dev resources, and webhooks.
- Dev Mode focused-node and CSS inspection support.
- ES6-safe plugin build for the Figma sandbox.
- Fixed `ahd-figma upgrade` alias handling and macOS signing.

## Removed Direction

`ahd-illustrator` was experimental and has been retired. The remote Illustrator branch was deleted. Tag `v0.12.0` remains abandoned history.
