AI Happy Design exposes **150+ commands** across **14+ tool domains**. Every command follows the `domain.action` naming pattern and can be invoked via CLI, MCP, or batch mode.

## Discovery

```bash
# List all tools with descriptions
ai-happy-design tools --llm --json

# List actions for a specific domain
ai-happy-design actions paint

# Get JSON schema for a command
ai-happy-design schema text.create --json

# Get all schemas (for LLM context)
ai-happy-design schema --all

# Get design guide
ai-happy-design guide --topic all
```

## Command Syntax

<Tabs>
  <TabItem label="CLI">

```bash
ai-happy-design command <domain.action> '<json_params>'
```

## node

Create, modify, and manage Figma nodes.

| Command | Description | Key Params |
|---------|------------|------------|
| `node.create_frame` | Create a frame | name, x, y, width, height, parentId, color, cornerRadius, layoutMode, itemSpacing, padding, paddingTop/Right/Bottom/Left, primaryAxisAlign, counterAxisAlign, primaryAxisSizing, counterAxisSizing, layoutWrap, clipsContent, noFill |
| `node.get_info` | Get node information | nodeId |
| `node.get_tree` | Get node tree (add `compact:true` for flat array) | nodeId, depth, compact |
| `node.move` | Move a node | nodeId, x, y |
| `node.resize` | Resize a node | nodeId, width, height |
| `node.rotate` | Rotate a node | nodeId, rotation (degrees) |
| `node.set_opacity` | Set opacity | nodeId, opacity (0-1) |
| `node.set_blend_mode` | Set blend mode | nodeId, blendMode |
| `node.set_visibility` | Show/hide | nodeId, visible |
| `node.set_locked` | Lock/unlock | nodeId, locked |
| `node.rename` | Rename a node | nodeId, name |
| `node.delete` | Delete a node | nodeId |
| `node.clone` | Clone a node | nodeId |
| `node.modify` | Unified update (any props) | nodeId + any of: x, y, width, height, color, opacity, cornerRadius, rotation, text, fontSize, visible, name, isMask, etc. |
| `node.set_mask` | Create mask group | nodeId (mask shape), targetIds |

### node.create_frame: Full Options

```json
{
  "name": "Hero Section",
  "x": 0, "y": 0,
  "width": 1080, "height": 1920,
  "color": "#0a0a0a",
  "cornerRadius": 0,
  "layoutMode": "VERTICAL",
  "itemSpacing": 24,
  "padding": 32,
  "paddingTop": 48, "paddingRight": 32,
  "paddingBottom": 48, "paddingLeft": 32,
  "primaryAxisAlign": "CENTER",
  "counterAxisAlign": "CENTER",
  "primaryAxisSizing": "AUTO",
  "counterAxisSizing": "FIXED",
  "layoutWrap": "NO_WRAP",
  "clipsContent": true,
  "parentId": "optional_parent_id",
  "noFill": false
}
```

### node.modify: Unified Update

`node.modify` is the Swiss Army knife. Update any node property in a single call:

```bash
ai-happy-design command node.modify \
  '{"nodeId":"42:248","x":100,"y":200,"width":500,"opacity":0.8,"cornerRadius":16,"name":"Updated Frame"}'
```

### node.get_tree: Compact Mode

Add `compact: true` for a flat summary array that uses 3-5x fewer tokens than nested tree output:

```bash
ai-happy-design command node.get_tree '{"nodeId":"42:248","compact":true}'
```

Returns: `[{id, type, name, x, y, w, h, childCount, parentId, depth}]`

## text

Create and style text nodes.

| Command | Description | Key Params |
|---------|------------|------------|
| `text.create` | Create text node | text, x, y, fontFamily, fontStyle, fontSize, parentId, name, color, width, textAlign, lineHeight, lineHeightUnit, layoutSizingHorizontal, layoutSizingVertical, layoutGrow, layoutAlign |
| `text.set_content` | Set text content | nodeId, text |
| `text.set_font` | Set font family/style | nodeId, fontFamily, fontStyle |
| `text.set_size` | Set font size | nodeId, fontSize |
| `text.set_weight` | Set font weight | nodeId, fontWeight |
| `text.set_color` | Set text color | nodeId, color |
| `text.set_align` | Set alignment | nodeId, textAlign (LEFT, CENTER, RIGHT, JUSTIFIED) |
| `text.set_spacing` | Set spacing | nodeId, letterSpacing, lineHeight, paragraphSpacing |
| `text.set_case` | Set text case | nodeId, textCase (ORIGINAL, UPPER, LOWER, TITLE) |
| `text.set_decoration` | Set decoration | nodeId, textDecoration (NONE, UNDERLINE, STRIKETHROUGH) |
| `text.get_segments` | Get styled segments | nodeId |
| `text.load_font` | Load a font | fontFamily, fontStyle |
| `text.list_fonts` | List available fonts | fontFamily (optional filter substring) |
| `text.set_style_id` | Apply text style | nodeId, styleId |
| `text.set_range_style` | Style character ranges | nodeId, ranges (array of objects with match or start+end, bold, italic, color, fontSize, fontFamily, fontStyle, letterSpacing, lineHeight, textDecoration, textCase, hyperlink) |

### text.create: Important Notes

- Use **`color`** (not `fillColor`) for text color
- Use **`fontStyle`** (not `fontWeight`). Values: "Regular", "Bold", "Medium", "SemiBold", etc.
- Set **`width`** to enable text wrapping
- Always specify **`lineHeightUnit: "PERCENT"`** with `lineHeight`

```bash
ai-happy-design command text.create '{
  "parentId": "42:248",
  "text": "Hello World",
  "fontSize": 28,
  "fontFamily": "Inter",
  "fontStyle": "Bold",
  "color": "#FFFFFF",
  "x": 32, "y": 32,
  "width": 400,
  "lineHeight": 130,
  "lineHeightUnit": "PERCENT"
}'
```

### text.set_range_style: Styled Ranges

Apply different styles to specific parts of text:

```json
{
  "nodeId": "42:249",
  "ranges": [
    {"match": "bold text", "bold": true, "color": "#FFD600"},
    {"start": 0, "end": 5, "fontSize": 24, "italic": true},
    {"match": "link text", "hyperlink": "https://example.com", "textDecoration": "UNDERLINE"}
  ]
}
```

## shape

Create geometric shapes and images.

| Command | Description | Key Params |
|---------|------------|------------|
| `shape.create_rectangle` | Create rectangle | name, x, y, width, height, parentId, color, cornerRadius |
| `shape.create_ellipse` | Create ellipse | name, x, y, width, height, parentId, color |
| `shape.create_polygon` | Create polygon | name, x, y, width, height, parentId, color, pointCount |
| `shape.create_star` | Create star | name, x, y, width, height, parentId, color, pointCount, innerRadius |
| `shape.create_line` | Create line | name, x, y, width, parentId, color |
| `shape.create_from_svg` | Create shape from SVG | name, x, y, svgPath, parentId, width, height |
| `shape.create_image` | Place an image (one-step) | imageData, x, y, width, height, parentId, scaleMode, name, cornerRadius |

### Image Data Formats

The `imageData` parameter accepts:
- **Base64**: raw base64 encoded string
- **Data URL**: `data:image/png;base64,...`
- **File path**: `/tmp/photo.jpg`, `~/images/logo.png`
- **HTTP URL**: `https://example.com/image.jpg`

### Image Scale Modes

| Mode | Behavior |
|------|----------|
| `FILL` | Crop to fit container (most common) |
| `FIT` | Preserve aspect ratio, may letterbox |
| `CROP` | Manual crop region |
| `TILE` | Repeat pattern |

### Shadow Recipes

```bash
# Subtle (cards, inputs)
ai-happy-design command effect.add_shadow \
  '{"nodeId":"ID","shadowType":"DROP_SHADOW","color":{"r":0,"g":0,"b":0,"a":0.1},"offsetX":0,"offsetY":2,"radius":8}'

# Elevated (modals)
ai-happy-design command effect.add_shadow \
  '{"nodeId":"ID","shadowType":"DROP_SHADOW","color":{"r":0,"g":0,"b":0,"a":0.3},"offsetX":0,"offsetY":8,"radius":32}'

# Accent glow
ai-happy-design command effect.add_shadow \
  '{"nodeId":"ID","shadowType":"DROP_SHADOW","color":{"r":1,"g":0.84,"b":0,"a":0.15},"offsetX":0,"offsetY":4,"radius":24}'
```

### document.find_free_space

Always call this before creating root-level frames to avoid overlapping existing work:

```bash
ai-happy-design command document.find_free_space \
  '{"width": 1080, "height": 1920}'
```

Returns an 8px-grid-snapped `x, y` position plus a list of all existing frames.

### document.find_nodes

Unified search across name, type, and text content:

```bash
# Find by name
ai-happy-design command document.find_nodes '{"query": "Hero"}'

# Find by type
ai-happy-design command document.find_nodes '{"nodeType": "TEXT"}'

# Find by text content
ai-happy-design command document.find_nodes '{"textContent": "Welcome"}'
```

<Aside type="note">
`document.scan_by_type` scans ALL pages in the document, not just the current page. Use `document.find_nodes` with `nodeType` for page-specific scans.
</Aside>

## export

Export frames and nodes to files.

| Command | Description | Key Params |
|---------|------------|------------|
| `export.image` | Export as PNG/JPG | nodeId, format (PNG, JPG), scale |
| `export.svg` | Export as SVG | nodeId, scale |
| `export.pdf` | Export as PDF | nodeId, scale |
| `export.batch` | Export multiple frames | nodeIds (comma-separated), format, scale |

Exports auto-save to the OS temp directory (e.g., `/tmp/ahd-export-*`). The response includes the file path so you can open or read the file directly.

Default export scale is **2x** for crisp output on retina displays. Use `scale: 1` for very large frames to avoid memory issues.

```bash
# Export as 2x PNG
ai-happy-design command export.image \
  '{"nodeId":"42:248","format":"PNG","scale":2}'

# Batch export multiple frames
ai-happy-design command export.batch \
  '{"nodeIds":"42:248,42:250,42:252","format":"PNG","scale":2}'
```

<Aside type="note">
SVG and JSON exports return raw text (not base64). The CLI checks the `format` field to determine encoding.
</Aside>

## design

Design intelligence tools.

| Command | Description | Key Params |
|---------|------------|------------|
