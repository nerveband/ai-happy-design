AI Happy Design can create full presentation decks in Figma with consistent branding, auto-layout for content, and batch export for distribution.

## Slide Sizes

| Format | Size (px) | Aspect Ratio |
|--------|----------|-------------|
| Standard (16:9) | 1920 x 1080 | Widescreen |
| Wide (16:10) | 1920 x 1200 | MacBook native |
| Classic (4:3) | 1440 x 1080 | Projector |
| Tall / Mobile | 1080 x 1920 | Vertical |

## Compute Tokens for Slides

```bash
ai-happy-design command design.compute_tokens '{"width": 1920, "height": 1080}'
```

For a 1920px-wide deck:
- Hero: ~200px
- Title: ~152px
- Heading: ~112px
- Body: ~84px
- Caption: ~64px

## Consistent Branding Across Slides

To maintain brand consistency across an entire deck:

1. **Compute tokens once** for the slide dimensions
2. **Define a color palette** and use it across all slides
3. **Use the same font pairings** (e.g., Space Grotesk for headings, Inter for body)
4. **Use consistent padding** (e.g., 120px horizontal, 80px vertical)
5. **Use consistent card styling** (same cornerRadius, fill opacity, stroke)

## Batch Export

Export all slides at once:

```bash
# Find all slide frames
ai-happy-design command document.find_nodes '{"nodeType":"FRAME"}'

# Batch export as PNG
ai-happy-design command export.batch \
  '{"nodeIds":"42:248,42:260,42:272,42:284","format":"PNG","scale":2}'

# Export individual slide as PDF
ai-happy-design command export.pdf '{"nodeId":"42:248","scale":2}'
```

## Building a Full Deck

For a complete presentation, create one batch file per slide type and chain them:

```bash
# Create all slides
ai-happy-design batch slides/title.json
ai-happy-design batch slides/agenda.json
ai-happy-design batch slides/metrics.json
ai-happy-design batch slides/priorities.json
ai-happy-design batch slides/closing.json

# Export all
ai-happy-design command export.batch \
  '{"nodeIds":"ALL_SLIDE_IDS","format":"PNG","scale":2}'
```

Or combine everything into a single batch file for maximum throughput (27 ops/sec).

## Tips for Presentations

<CardGrid>
  <Card title="Auto-layout everything">
    Use auto-layout for all slide content. It handles spacing and alignment automatically.
  </Card>
  <Card title="Consistent text hierarchy">
    Title: 48-72px. Body: 24-32px. Caption: 16-20px. Same across all slides.
  </Card>
  <Card title="The 8px grid">
    All spacing, padding, and sizing on multiples of 8.
  </Card>
  <Card title="Export at 2x">
    Crisp output for projectors and screens. Use `scale: 2` on all exports.
  </Card>
</CardGrid>

- **Name every slide** clearly for easy navigation in Figma's layers panel
- **Use FILL sizing** for text and metric cards to distribute space evenly
- **Add subtle card backgrounds** for metrics, callouts, and quotes
- **Keep bullet points concise**, one line per point, 28-32px
