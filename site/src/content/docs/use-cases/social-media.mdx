## Getting Started: Compute Tokens First

Always start by computing design tokens for your canvas size:

```bash
ai-happy-design command design.compute_tokens \
  '{"width": 1080, "height": 1350}'
```

This returns exact font sizes, spacing, padding, and card dimensions optimized for the canvas. For a 1080px canvas: body = 48px, heading = 84px, hero = 152px.

## Using the Slide Composite

For faster single-slide creation, use the built-in composite command:

```json
[
  {
    "command": "bulk.slide",
    "params": {
      "canvas": "1080x1350",
      "bg": "#0C1E2C",
      "gradient": {"from": "#0C1E2C", "to": "#1a3a5c"},
      "elements": [
        {"type": "eyebrow", "text": "Design Tip #1"},
        {"type": "headline", "text": "Use Auto-Layout for Everything"},
        {"type": "body", "text": "It works exactly like CSS flexbox."},
        {"type": "counter", "text": "1/5"},
        {"type": "cta", "text": "Save for later"}
      ]
    }
  }
]
```

Supported element types: `eyebrow`, `headline`, `body`, `bar`, `counter`, `cta`, `url`, `stats`, `progress`.

## Content Calendar Workflow

For producing a full week of social content:

### 1. Create a batch file for each post

Organize your batch files in a `content/` directory:

```
content/
  monday-post.json
  tuesday-carousel.json
  wednesday-story.json
  thursday-post.json
  friday-carousel.json
```

### 2. Use consistent design tokens

Call `design.compute_tokens` once per canvas size and reuse the values across all batches.

### 3. Run all batches

```bash
for file in content/*.json; do
  ai-happy-design batch "$file" --lint
done
```

### 4. Batch export all frames

```bash
ai-happy-design command export.batch \
  '{"nodeIds":"1:2,1:3,1:4,1:5,1:6,1:7,1:8","format":"PNG","scale":2}'
```

## Tips for Social Media Designs

<CardGrid>
  <Card title="Compute tokens first">
    Always call `design.compute_tokens` to get proper font sizes for the canvas. Do not guess.
  </Card>
  <Card title="Minimum readable text">
    Caption text should be 36px minimum at 1080px width (renders as ~12px on phone screens).
  </Card>
  <Card title="Use the right tier">
    Short headlines (1-3 words): hero/title tier. Medium (4-10 words): heading. Long paragraphs: body tier.
  </Card>
  <Card title="Export at 2x">
    Always export at scale 2 for crisp output on retina displays. This is the default.
  </Card>
</CardGrid>

- **All text must be readable at a glance.** Social content has no room for fine print
- **Name every slide** ("Slide 1 - Cover", "Slide 2 - Tip 1") for easy navigation in Figma
- **Use gradient backgrounds** for visual depth on dark themes
- **Use fully opaque hex colors** for gradient stops to avoid washed-out results
